# NewOrbit Services — Project Portfolio

> **Live site:** https://ishansharma31030-lgtm.github.io/New/

A comprehensive project management portfolio for **NewOrbit Services**, headquartered in Jaipur, Rajasthan, India.

## Features

- 220+ engineering projects across 10 service categories
- Interactive 3D project viewer (Three.js)
- Live search, category/status/year filtering
- Dark theme with blue accent branding
- Responsive design for all devices
- Client testimonials and contact form

## Tech Stack

Pure HTML / CSS / JavaScript — no build step required.  
3D visualization powered by [Three.js](https://threejs.org/).

## Deployment

The site is deployed automatically to GitHub Pages on every push to `main` via the workflow at `.github/workflows/deploy.yml`.

To enable GitHub Pages in your fork:
1. Go to **Settings → Pages**
2. Set **Source** to `GitHub Actions`
3. Push to `main` — the workflow will deploy the site
