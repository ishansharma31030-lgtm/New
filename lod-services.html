What is LOD?

Understanding the Level of Development Framework

Level of Development (LOD) is a reference framework established by BIMForum and the American Institute of Architects (AIA) that defines the degree of completeness of a BIM model element. LOD specifications range from LOD 100 (conceptual) through LOD 500 (verified as-built), each requiring progressively more geometric and parametric data.

LOD
100

LOD 100 — Conceptual Design

The BIM element may be graphically represented in the Model with a symbol or other generic representation. Information attached to the element is not location-specific. It is used for analysis based on volume, area, and orientation derived from overall building massing.

What's Included
  • Basic massing elements and zones
  • Approximate overall dimensions
  • General building orientation
  • Conceptual system identification
  • Rough cost estimate data
Typical Use Cases
  • Feasibility studies
  • Pre-design analysis
  • Overall project cost modeling
  • Owner decision making
  • Site planning studies
MEP Application
  • Mechanical zones shown schematically
  • No actual MEP systems modeled
  • Energy zone boundaries defined
  • Rough system type identification
  • Utility connection points estimated
Geometry Detail
  • 2D symbols or generic 3D shapes
  • No precise dimensions required
  • Location not specifically defined
  • No connectivity shown
  • No manufacturer data
LOD
200

LOD 200 — Approximate Geometry

The BIM element is modeled as a generic system, object, or assembly with approximate quantities, size, shape, location, and orientation. Information attached may include non-graphic data. This level supports coordination in schematic and design development phases.

What's Included
  • Generic placeholder elements
  • Approximate size and shape
  • General routing shown
  • Approximate quantities
  • System type defined
Typical Use Cases
  • Schematic design phase
  • Coordination planning
  • Gross area calculations
  • Initial clash avoidance
  • Energy analysis input
MEP Application
  • Generic HVAC equipment placed
  • Approximate duct/pipe routing
  • Equipment sizes estimated
  • Mechanical room footprint shown
  • Shaft locations identified
Geometry Detail
  • Generic 3D objects used
  • Approximate dimensions only
  • General location specified
  • No specific connections
  • No manufacturer-specific data
LOD
300

LOD 300 — Precise Geometry

The BIM element is modeled as a specific system, object, or assembly in terms of quantity, size, shape, location, and orientation. Non-graphic information may be attached. This level supports construction document production and permit submission.

What's Included
  • Specific system elements
  • Accurate dimensions and location
  • Defined quantities
  • Non-generic objects
  • Basic specification data
Typical Use Cases
  • Construction documents
  • Permit submission drawings
  • Bid documentation
  • Owner presentations
  • Code compliance review
MEP Application
  • Exact equipment specifications
  • Precise duct/pipe routing
  • Connection points shown
  • Insulation types defined
  • Valve and fitting locations
Geometry Detail
  • Specific manufacturer families
  • Accurate 3D geometry
  • Exact location coordinates
  • System connectivity shown
  • Rough clearances included
LOD
350

LOD 350 — Construction Elements

The BIM element is modeled as a specific system, object, or assembly including interfaces with other building systems. This level is coordination-ready and includes supports, connections, and anchorage. Essential for multi-discipline BIM coordination and clash detection.

What's Included
  • Interface details with other systems
  • Support and anchorage shown
  • Connection details defined
  • Clearance requirements modeled
  • Coordination-ready geometry
Typical Use Cases
  • Construction coordination
  • Multi-discipline clash detection
  • Fabrication preparation
  • Subcontractor scope definition
  • Installation planning
MEP Application
  • Hanger and support points shown
  • Sleeve locations in structure
  • Clearances fully verified
  • Equipment access paths modeled
  • Pipe/duct penetrations shown
Geometry Detail
  • Full interface geometry
  • Support hardware modeled
  • Exact clearance zones
  • Structural penetrations defined
  • Seismic bracing locations
LOD
400

LOD 400 — Fabrication-Ready

The BIM element is modeled as a specific system, object, or assembly with complete detail for fabrication, assembly, and installation. This level contains all necessary information for ordering, fabricating, and installing the element with no additional design required.

What's Included
  • Complete fabrication details
  • Assembly information
  • Installation instructions data
  • Part numbers and ordering info
  • Full specification data
Typical Use Cases
  • Shop drawing production
  • Prefabrication workflows
  • Detailed cost estimating
  • Material procurement
  • Off-site fabrication
MEP Application
  • Full pipe spool drawings possible
  • Duct fabrication details complete
  • Equipment pad dimensions exact
  • All fittings and accessories modeled
  • Wire routing detailed
Geometry Detail
  • Complete fabrication geometry
  • Manufacturer-specific details
  • Exact material specifications
  • All connectors and fittings
  • Tolerance information included
LOD
500

LOD 500 — As-Built Verified

The BIM element is a field-verified representation of the actual installed conditions in terms of size, shape, location, quantity, and orientation. LOD 500 is used as the foundation for facility management, operations, and the building's digital twin throughout its lifecycle.

What's Included
  • Field-verified geometry
  • Actual installed conditions
  • Operations & maintenance data
  • Serial numbers and nameplate data
  • Warranty information
Typical Use Cases
  • Facility management (CAFM/IWMS)
  • Operations & maintenance
  • Digital twin platform
  • Building lifecycle planning
  • Future renovation base model
MEP Application
  • Actual installed equipment verified
  • Valve tags and IDs populated
  • Nameplate data recorded
  • Maintenance schedules linked
  • As-installed pipe/duct routes
Geometry Detail
  • Field-surveyed or scan-verified
  • Exact as-installed positions
  • All deviations from design noted
  • Full asset data populated
  • Linked to CMMS/FM systems
